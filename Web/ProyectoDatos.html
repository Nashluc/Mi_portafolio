Proyecto de Análisis de Datos

Exploración, limpieza y visualización de datos.

Sobre el proyecto

Este proyecto consiste en analizar un conjunto de datos para identificar información relevante y encontrar patrones.

Se aplicaron técnicas de limpieza, organización y visualización para presentar los resultados de una manera clara y comprensible.

Tecnologías utilizadas

Python

Pandas

Matplotlib
